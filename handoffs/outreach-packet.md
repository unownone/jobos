# Outreach packet

Apply seeds this after submit. Outreach completes people and sends.

```yaml
outreach_packet:
  job_link: ""
  applied_at: ""
  resume: assets/resume/resume-primary.pdf
  hook: ""                 # one true sentence from the apply note
  ask: "15-minute chat"
  policy: teammates_and_recruiter   # or founders_ok for small cos
  people:
    - name: ""
      title: ""
      linkedin_url: ""
      email: ""
      email_confidence: unknown
      channel_order: [email, linkedin_dm]
  do_not_contact: []
```

Email must include the PDF attachment. LinkedIn DM asks for a chat and does not assume PDF support.
