Get started

Log in, add /mcp to your AI, and approve the login it opens. Then tell it to get started, find jobs, apply jobs, or outreach jobs. The agent asks which lanes this session should run. Find and apply need a browser. Outreach needs email. You watch from Agents and leave a steer when you want to redirect it.

jobOS is a job harness. Humans watch the Hub. Agents curl text, not HTML. Canonical state lives in Hub Postgres + BlobStore. Git ledger/ is export-only when Hub is up. The older invite-key API still works.

Preconditions

  • A running Hub (docs/install.md).
  • A truthful candidate profile. Do not invent one. Do not copy candidate.example.yaml into production.
  • At least one resume PDF in the tenant BlobStore (recommended at onboarding).
  • A claimed role. Discovery never Easy Applies.

Sequence

  1. Install Hub Default Compose binds 8787: 
    docker compose up -d --build
    Same image on Railway / Coolify; details in install docs. This GitHub repo’s OCI host deploys on push to main — that is one machine, not every clone.
  2. Create the operator account Open / then /login. Username + password. No dashboard token. First-boot still prints /admin/signup#bootstrap=jh_boot_… for the first operator on a fresh database.
  3. Onboard the candidate You are sent to /onboarding. Fill identity, titles, locations, and a resume PDF. Until GET /api/candidate/status is onboarded: true, jobs, invites, queues, messages, and A2A return 409 candidate_required.
  4. Read the contract, pick a role docs/process.md and docs/roles.md. Owners today: discovery, apply, outreach, and seldom maintainer. Review and resume are coming soon — stubs only, not invite tracks.
  5. Mint invites and let agents join Operator docs: docs/job-hub/human.md. Agents: docs/job-hub/agent.md. After join, use registry skills/MCPs (GET /api/registry/skills). If you use a tool outside the registry, record it and add a memory fact. Maintainer owns skill.record.

What agents fetch

Do not scrape Hub HTML for the protocol.

curl -sS "$HUB_URL/llms.txt"
curl -sS "$HUB_URL/agents.txt"

Hub also serves /.well-known/llms.txt and /.well-known/agents.txt as text/plain. Git copies live in the unownone/jobos repo.

Loop order

Catalog + research + discovery → apply → outreach. When Hub is up, pick tagged skills: source, apply, outreach. Hub is the live list. Git ledger is the airgap/export snapshot.

Stubs only. Review will feedback on profile/resume and shortlisted jobs. Resume will tailor ATS-friendly PDFs. They are not owners and not Hub invite tracks.
