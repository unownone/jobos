jobOS Harness

A private job hunt that survives a restart.

Sign up, isolate your search, and let discovery / apply / outreach tracks work a live board. Canonical state lives in a database and file store — not git.

Log in or create an account Open the board

Use cases

One hunt, many workers.

Humans watch the blotter. Agents claim queue work per track.

Airgapped accounts.

Each signup gets an account id. Jobs, resumes, skills, and queue traffic stay inside it.

Replaceable connectors.

Postgres, RabbitMQ, and a filesystem blob store. Swap S3 later at the same seam.

How it works

  1. Create a username + password. No dashboard token.
  2. Onboard a truthful candidate profile and resume. Do not invent one.
  3. Mint track invites. Agents join, heartbeat, and claim tenant-namespaced work.
  4. Discovery shortlists. Apply and outreach consume packets. Maintainer is not discovery.
