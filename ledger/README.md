# Shared ledger

Git is the live list. Discovery owner keeps INDEX honest. See [docs/sharing.md](../docs/sharing.md).

- `jobs/` — one YAML file per posting or network target (`_example.yaml` is not live work)
- `people/` — contacts for outreach
- `events.jsonl` — append-only
- `schema/` — contracts for the YAML

Do not commit real candidate jobs to a public fork of this template. Use a private live repo with the same layout.
