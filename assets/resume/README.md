# Resume pack

Put the live PDFs here locally. They are gitignored.

Suggested filenames:

- `resume-primary.pdf` — default attach for email and ATS
- `resume-backend.pdf` — optional variant
- `resume-fullstack.pdf` — optional variant
- `one-pager.pdf` — optional short version for exec outreach

Never invent experience. Variants may reorder and emphasize; they may not add claims.
